# Working preferences

- Mock-ups, screenshots and other visuals: send them as **PNG images** directly in the chat
  (render phone screens at 390×844, deviceScaleFactor 2, one image per screen).
  Do not rely on artifact/canvas links for these. The owner usually views them on a phone,
  where those links don't load.
- **Any change to the interface** (anything the owner sees or taps: layout, screens, buttons, wording
  on screen, new pages) needs a **mock-up first**, sent as PNG images as above, and the owner's OK
  before any code is changed. Invisible changes (bug fixes, server-side work) don't need one; say what
  changed afterwards.
